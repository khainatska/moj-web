# Style guide

Táto referencia opisuje vizuálnu identitu webu. Dizajn je teplý, elegantný a
čokoládový, s veľkým množstvom voľného miesta, jemnými tenkými rámikmi a
minimom tieňov. Ružová farba sa nepoužíva.

## Farby

| Použitie | Hex |
| --- | --- |
| Pozadie stránky | `#F3EBE6` |
| Karty, polia formulára | `#FAF5F1` |
| Svetlé bloky — sekcie, mapa | `#E9DDD5` |
| Nadpisy a hlavný text | `#4A2A1B` |
| Sekundárny text | `#7A5A4A` |
| Akcent — ceny, ikony, odkazy | `#9A5535` |
| Primárne tlačidlo | `#7A4B30` |
| Text na primárnom tlačidle | `#FFFFFF` |
| Rámiky | `#5A3220` |
| Rámik karty | `#E0D0C6` |
| Placeholder formulára | `#A08878` |

Nadpisy aj hlavný text používajú teplú tmavohnedú farbu `#4A2A1B`.
Sekundárne informácie používajú `#7A5A4A`, akcenty `#9A5535`.

## Písma a typografia

- Nadpisy: `Georgia, serif`
- Bežný text: `system-ui, "Segoe UI", sans-serif`
- Základná veľkosť textu: `16px`
- Výška riadku: `1.6`
- Letter-spacing: `0.02em`
- H1: `48px`
- H2: `32px`
- H3: `20px`

Nadpisy majú jasnú vizuálnu hierarchiu. Telo textu sa má držať jednotnej
čitateľnej veľkosti a riadkovania.

## Tlačidlá

### Primárne tlačidlo

- Pozadie: `#7A4B30`
- Text: `#FFFFFF`
- Border-radius: `999px`
- Padding: `12px 28px`
- Hover: pozadie `#8F5C3E`

### Sekundárne tlačidlo

- Bez výplne
- Rámik: `1px solid #5A3220`
- Text: `#5A3220`
- Border-radius: `999px`
- Padding: `12px 28px`
- Hover: pozadie `#E9DDD5`

### Fokus

Pri zameraní klávesnicou všetky interaktívne prvky používajú viditeľný obrys
`2px solid #9A5535`. Nedochádza k zakrytiu obrysu ani odstráneniu štandardného
focus stavu.

## Karty

- Pozadie: `#FAF5F1`
- Rámik: `1px solid #E0D0C6`
- Border-radius: `16px`
- Tieň: žiadny alebo veľmi jemný
  `0 1px 3px rgba(74, 42, 27, 0.08)`

Karty majú pôsobiť ľahko a vzdušne. Využívajú zaoblené rohy, jemné rámiky
a žiadny alebo iba veľmi jemný tieň.

## Formuláre

- Polia: pozadie `#FAF5F1`
- Rámik: `1px solid #5A3220`
- Border-radius: `12px`
- Placeholder text: `#A08878`

Polia majú zreteľný rámik a dostatočné vnútorné odsadenie pre pohodlné zadávanie
textu. Aktívny stav sa zvýrazňuje farebným akcentom a viditeľným focus obrysom.

## Hlavička a pätička

### Hlavička

- Pozadie: `#F3EBE6`
- Spodná čiara: `1px solid #E0D0C6`
- Aktívna položka menu: podčiarknutie `#9A5535`

### Pätička

- Pozadie: `#E9DDD5`
- Text: `#4A2A1B`

## Rozloženie a priestor

Používajú sa veľké vnútorné a vonkajšie odsadenia, aby dizajn pôsobil pokojne
a elegantne. Svetlé bloky, kartové sekcie a mapa môžu vychádzať zo farby
`#E9DDD5`; obsah zostáva čitateľný a oddelený jemnými hranicami.
